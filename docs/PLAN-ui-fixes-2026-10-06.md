**Инварианты, которые нельзя нарушить:**
- разметочные слои редактора/предпросмотра не попадают в PDF и печать (DOM-слой `preview-only`, `print.css:40`);
- одно действие пользователя = одна запись в истории (`setCanvasJSON`), иначе ломается undo;
- доступность: убираемый визуальный индикатор заменяется `sr-only` live-region, а не исчезает бесследно;
- работоспособность при ширине 1024px (`index.css:22` задаёт min-width 1024px).

## 4. Блок 4 — вставка текста (4а, 4б)

### 4.1. 4а: автоматический перенос строк и уменьшение кегля под формат этикетки

1. Новый `src/utils/textFitter.ts` (чистая логика, тестируемая):
   - вход: текст, объект, доступная область этикетки (`selectedFormat.width_mm/height_mm`), `sheetSettings.safetyMargin_mm`;
   - отступ `inset = safetyMargin_mm > 0 ? safetyMargin_mm : 1` мм; `W = width_mm − 2·inset`, `H = height_mm − 2·inset` (в базовых px сцены, `MM_PER_PX` из `canvasHelpers.ts:29`);
   - перенос: текст кладём в `fabric.Textbox` с `width = W` (авто-перенос, `splitByGrapheme: false`) — вместо `IText`, который не переносит длинную строку;
   - подбор кегля: от текущего `fontSize` вниз шагом 0.5pt до минимума 4pt, пока вычисленная высота `Textbox` не станет ≤ `H`; если и на 4pt не влезает — не уменьшаем дальше, показываем предупреждение «Текст не помещается в этикетку» (в Toast/`alert`);
   - никогда не увеличиваем кегль и не трогаем текст, который уже помещается (порог: ширина одной строки > `W` **или** высота > `H`).
2. Конвертация `IText → Textbox` без потерь: перенести `toObject(CUSTOM_PROPS)` (`canvasHelpers.ts:4-17`), позицию, угол, масштаб→`fontSize`, z-порядок (`canvas.insertAt(index, newObj)`), затем `canvas.remove(old)`. Вся операция — под `withoutHistory` + один `setCanvasJSON(serializeCanvas(canvas))` + `bumpObjectRevision()`, чтобы undo откатывал вставку одним шагом.
3. Привязка к путям вставки:
   - канвас (основной путь): слушатель `paste` на документе с проверкой, что редактируется текстовый объект (`active.isEditing`) или выделен текст и фокус не в поле панели; после вставки (следующий тик) прогнать `fitTextToLabel`;
   - `TextPanel.tsx:301-308` — `onPaste` на `<textarea>`: после вставки прогнать тот же фиттер по `selectedObject` (сейчас вставка в панель просто раздувает текст без переносов);
   - санитайз текста: нормализовать `\r\n`, схлопнуть 3+ переводов строки в 2.
4. После подгонки объект сдвигается внутрь этикетки: `left ≥ inset`, `left + bbox.width ≤ W + inset`, аналогично `top`; если не влезает — прижимаем к ближайшей границе, а не выталкиваем за лист.

### 4.2. 4б: учёт форматирования абзаца при вставке и сдвиг в нужную сторону

**Трактовка (подтверждена заказчиком).** Вставленный фрагмент наследует абзацные настройки элемента — `textAlign`, `lineHeight`, `fontSize`, `fontFamily`, `charSpacing` — и позиция элемента корректируется так, чтобы приросший текст остался выровненным и внутри этикетки:

1. Настройки берём с самого объекта (`selectedObject`), а не из состояния панели: панель уже пишет их в объект (`TextPanel.tsx:136-145`).
2. Направление сдвига задаётся `textAlign`:
   - `left` — блок растёт вправо (сдвиг 0 по X);
   - `right` — влево: после роста `left` уменьшается на прирост ширины;
   - `center` — симметрично: `left` уменьшается на половину прироста;
   по вертикали блок растёт вниз, а если упирается в нижнюю/безопасную границу — сдвигается вверх на недостающую величину.
3. Если вставка идёт в позицию курсора внутри существующего абзаца — новые символы не получают «чужих» стилей: явные посимвольные стили не переносятся, применяется только абзацное форматирование.
4. Результат — один шаг истории и обновлённые `TextPanel` (`bumpObjectRevision`).

**Приёмка блока 4.** Вставка 300 символов в пустой элемент на формате 38×16.9 → текст переносится, кегль уменьшен, объект внутри этикетки, undo откатывает целиком; при `textAlign: center` блок остаётся центрированным после вставки; текст, который уже помещается, не меняет кегль; вставка в панель «Текст» даёт тот же результат, что вставка на канвасе.

## 7. Риски и как их закрываем

| Риск | Митигация |
|---|---|
| File System Access API есть только в Chromium (и требует https/localhost) | Ветка fallback на скачивание; в справке честно написать, что «сохранение в тот же файл» доступно в Chrome/Edge |

| Удаление индикаторов ломает доступность | `sr-only` live-region + `title` + `aria-label` |
| Уменьшение кнопок слоёв < 24px (регрессия к `UI-POLISH-TODO.md` п. 4) | Строка целиком кликабельна, у кнопок `title`/`aria-label`, комментарий в коде; замер имени слоя |

| Миниатюры 240×160 раздувают JSON библиотеки | Оценка размера (≈5–15 КБ/элемент); предупреждение при экспорте > 5 МБ, ленивая миграция старых миниатюр |

| Поле имени `flex-1` ломает вёрстку на 1024px | `min-w-[14rem]`, подписи кнопок остаются `hidden xl:inline`, проверка на 1024 и 1920 |
