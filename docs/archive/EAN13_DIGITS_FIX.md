# Исправление позиций цифр EAN-13

## Проблема

Цифры под штрихкодом EAN-13 располагались неравномерно и слипались в две группы без правильных промежутков.

## Причина

Предыдущая реализация использовала неправильную формулу для расчёта позиций цифр. Функция пыталась вычислять позиции на основе границ штрихов, но не учитывала стандартную структуру EAN-13 (95 модулей).

## Решение

Заменена функция `computeDigitPositions` на новую реализацию, которая использует точную геометрию EAN-13:

### Структура EAN-13 (95 модулей):
- **Защитные слева**: 3 модуля
- **Левая половина**: 42 модуля (6 цифр по 7 модулей)
- **Центральные защитные**: 5 модулей
- **Правая половина**: 42 модуля (6 цифр по 7 модулей)
- **Защитные справа**: 3 модуля

### Позиции цифр (в модулях от minX):

**Первая цифра (индекс 0)**:
- Расположена слева вне штрихов
- Позиция: `minX - 3.5 модуля`

**Левая половина (цифры 2-7, индексы 1-6)**:
- Каждая цифра занимает 7 модулей
- Центры цифр: 6.5, 13.5, 20.5, 27.5, 34.5, 41.5 модулей

**Правая половина (цифры 8-13, индексы 7-12)**:
- Каждая цифра занимает 7 модулей
- Центры цифр: 53.5, 60.5, 67.5, 74.5, 81.5, 88.5 модулей

## Изменения в коде

### Файл: `src/utils/barcodeGenerator.ts`

**Удалены функции:**
- `computeEAN13DigitPositions()` - старая реализация
- `computeITF14DigitPositions()` - старая реализация

**Новая функция:**
```typescript
export function computeDigitPositions(
  bars: NormalizedBar[],
  format: 'ean13' | 'itf14',
  code: string
): Array<{ char: string; xFrac: number }>
```

### Ключевые изменения:

1. **Упрощённая структура**: одна функция вместо трёх
2. **Точные позиции**: используются фиксированные значения модулей
3. **Нормализация**: все позиции вычисляются относительно `totalWidth`
4. **Поддержка обоих форматов**: EAN-13 и ITF-14 в одной функции

### Пример расчёта для EAN-13:

```typescript
const module = totalWidth / 95;

const positions = [
  // Первая цифра слева (вне штрихов)
  { char: code[0], xFrac: minX - 3.5 * module / totalWidth },
  
  // Левая половина (цифры 2-7)
  { char: code[1], xFrac: minX + (6.5 * module) / totalWidth },
  { char: code[2], xFrac: minX + (13.5 * module) / totalWidth },
  { char: code[3], xFrac: minX + (20.5 * module) / totalWidth },
  { char: code[4], xFrac: minX + (27.5 * module) / totalWidth },
  { char: code[5], xFrac: minX + (34.5 * module) / totalWidth },
  { char: code[6], xFrac: minX + (41.5 * module) / totalWidth },
  
  // Правая половина (цифры 8-13)
  { char: code[7], xFrac: minX + (53.5 * module) / totalWidth },
  { char: code[8], xFrac: minX + (60.5 * module) / totalWidth },
  { char: code[9], xFrac: minX + (67.5 * module) / totalWidth },
  { char: code[10], xFrac: minX + (74.5 * module) / totalWidth },
  { char: code[11], xFrac: minX + (81.5 * module) / totalWidth },
  { char: code[12], xFrac: minX + (88.5 * module) / totalWidth },
];
```

## Результат

✅ Цифры EAN-13 теперь расположены правильно:
- Первая цифра слева вне штрихов
- 6 цифр равномерно под левой половиной
- 6 цифр равномерно под правой половиной
- Правильные промежутки между группами

✅ Цифры ITF-14:
- Все 14 цифр равномерно распределены по ширине

✅ Совместимость:
- Работает на канвасе (Fabric.js)
- Работает в PDF экспорте
- Работает в браузерной печати

## Тестирование

1. Создайте штрихкод EAN-13 с кодом `4604335164275`
2. Проверьте расположение цифр:
   - Первая цифра `4` должна быть слева вне штрихов
   - Цифры `604335` должны быть равномерно под левой половиной
   - Цифры `164275` должны быть равномерно под правой половиной
3. Увеличьте масштаб - цифры остаются на своих местах
4. Экспортируйте в PDF - раскладка сохраняется

## Влияние на другие компоненты

Изменение не требует обновления других компонентов, так как:
- Функция `computeDigitPositions` используется везде одинаково
- Интерфейс возвращаемых данных не изменился
- Все потребители используют единую функцию
