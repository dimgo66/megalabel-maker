## Как работает обрезка

### Процесс:

1. **Пользователь выбирает изображение** на канвасе
2. **Нажимает "✂️ Обрезать изображение"** в панели свойств
3. **Активируется режим обрезки:**
   - Создаётся полупрозрачный оверлей поверх канваса
   - Все другие объекты блокируются
   - Создаётся синяя пунктирная рамка поверх изображения
   - Рамка становится активным объектом
4. **Пользователь изменяет размер и положение рамки**
5. **Нажимает "✓ Применить обрезку":**
   - Вычисляются координаты обрезки
   - Создаётся временный canvas с обрезанной областью
   - Генерируется dataURL нового изображения
   - Оверлей и рамка удаляются
   - Старое изображение удаляется
   - Новое обрезанное изображение добавляется
   - Все объекты разблокируются
   - Изменения сохраняются в store
6. **Или нажимает "✕ Отмена":**
   - Оверлей и рамка удаляются
   - Изображение разблокируется
   - Все объекты разблокируются
   - Состояние не изменяется

### Технические детали:

**Создание оверлея:**
```typescript
const overlayRect = new fabric.Rect({
  left: 0,
  top: 0,
  width: canvas.getWidth(),
  height: canvas.getHeight(),
  fill: 'rgba(0, 0, 0, 0.3)',
  selectable: false,
  evented: false,
  excludeFromExport: true,
});

canvas.add(overlayRect);
canvas.sendObjectToBack(overlayRect);
```

**Блокировка объектов:**
```typescript
canvas.getObjects().forEach((obj) => {
  if (obj !== image) {
    obj.selectable = false;
    obj.evented = false;
  }
});
```

**Разблокировка после завершения:**
```typescript
canvas.getObjects().forEach((obj) => {
  obj.selectable = true;
  obj.evented = true;
});
```

## Сохранение в проект

Обрезанное изображение автоматически сохраняется через стандартный механизм `toJSON()`, так как мы физически создаём новое изображение с обрезанными данными. Дополнительные crop свойства не требуются.

## Преимущества нового подхода

✅ **Визуальная обратная связь** - оверлей чётко показывает область редактирования  
✅ **Защита от ошибок** - блокировка других объектов предотвращает случайные изменения  
✅ **Интуитивный интерфейс** - плавающая панель с кнопками внизу экрана  
✅ **Надёжная работа** - корректная обработка всех сценариев (применение, отмена)  
✅ **Автосохранение** - изменения автоматически сохраняются в store
