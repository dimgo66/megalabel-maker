### 2. Crop (обрезка) изображений

#### Компонент ImageCropPanel (`src/components/ImageCropPanel.tsx`)
- Создан компонент для обрезки изображений
- Функциональность:
  - Кнопка "Обрезать изображение" активирует режим обрезки
  - В режиме обрезки создаётся полупрозрачный прямоугольник с пунктирной рамкой

  - При применении изображение обрезается и заменяется новым

## Технические детали

### Undo/Redo
- Каждое изменение canvas сохраняется в массив истории
- При undo загружается предыдущее состояние через `canvas.loadFromJSON()`
- При redo загружается следующее состояние
- История автоматически очищается при добавлении нового состояния после undo

### Crop
- Используется временный canvas для обрезки изображения
- Координаты обрезки вычисляются относительно оригинального изображения
- После обрезки создаётся новое изображение из обрезанного canvas
- Старое изображение и прямоугольник обрезки удаляются
- Новое изображение добавляется на canvas и сохраняется в историю

## Горячие клавиши

- `Ctrl+Z` - Отменить последнее действие
- `Ctrl+Y` или `Ctrl+Shift+Z` - Повторить отменённое действие
- `Ctrl+S` - Сохранить проект
- `Ctrl+O` - Загрузить проект

## Использование

### Undo/Redo
1. Выполните любые действия на canvas (добавление текста, перемещение объектов и т.д.)
2. Нажмите `Ctrl+Z` или кнопку Undo для отмены
3. Нажмите `Ctrl+Y` или кнопку Redo для повтора

### Crop изображений
1. Загрузите изображение на canvas
2. Выберите изображение кликом
3. В правой панели нажмите "Обрезать изображение"
4. Измените размер и положение рамки обрезки
5. Нажмите "Применить" для обрезки или "Отмена" для отмены операции
