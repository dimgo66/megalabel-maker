# Шаг 4.3: Векторные штрихкоды

## Обзор

Штрихкоды теперь генерируются как **векторные SVG** вместо растровых PNG. Это обеспечивает:
- Идеальную чёткость при любом масштабе
- Качественную печать на лазерном принтере
- Компактное хранение в PDF (шаг 6)

## Архитектура векторного конвейера

```
1. JsBarcode → SVG (вектор)
2. SVG → Fabric.js Group (векторные пути)
3. Кастомные свойства → barcodeBars (нормализованные штрихи)
4. PDF экспорт → jsPDF.rect() (векторная отрисовка)
```

## Созданные файлы

### 1. `src/utils/barcodeGenerator.ts`

Функции для работы с векторными штрихкодами:

- **`generateBarcodeSVG(code, format, options)`** - генерирует SVG-строку штрихкода
- **`parseBarcodeBars(svgString)`** - парсит SVG и извлекает нормализованные штрихи (координаты 0..1)
- **`loadBarcodeIntoFabric(svgString)`** - загружает SVG в Fabric.js как векторную группу
- **`validateBarcode(code, format)`** - валидация кода
- **`addCheckDigit(code, format)`** - добавление контрольной цифры

### 2. `src/utils/barcodePdfRenderer.ts`

Заготовка для векторного рендеринга в PDF:

- **`drawBarcodeVectorPDF(doc, bars, x, y, w, h)`** - отрисовка штрихкода вектором в PDF
- **`hasBarcodeData(obj)`** - проверка наличия данных штрихкода
- **`extractBarcodeData(obj)`** - извлечение данных штрихкода

### 3. `src/components/BarcodeModal.tsx`

Модальное окно для создания/редактирования штрихкодов:

- Выбор формата (EAN-13 / ITF-14)
- Ввод кода с автоматической контрольной цифрой
- **Векторный SVG-превью** (масштабируется без потерь)
- Опция отображения цифр под штрихкодом
- Сохранение кастомных свойств: `barcodeFormat`, `barcodeValue`, `barcodeBars`, `barcodeSVG`

### 4. `src/components/BarcodePropertiesPanel.tsx`

Панель свойств для выбранного штрихкода:

- Информация: формат, код, количество штрихов
- Позиция (X, Y)
- Поворот (0-360°)
- Кнопка "Изменить код" (открывает BarcodeModal)
- Кнопка "Удалить штрих-код"

## Кастомные свойства объекта

Каждый штрихкод сохраняет в объекте Fabric.js:

```typescript
{
  barcodeFormat: 'ean13' | 'itf14',
  barcodeValue: string,           // полный код с контрольной цифрой
  barcodeBars: NormalizedBar[],   // массив штрихов (координаты 0..1)
  barcodeSVG: string              // исходная SVG-строка
}
```

Эти свойства сохраняются в файл проекта и восстанавливаются при загрузке.

## Нормализованные штрихи

```typescript
interface NormalizedBar {
  x: number;      // 0..1 (доля от ширины)
  y: number;      // 0..1 (доля от высоты)
  width: number;  // 0..1 (доля от ширины)
  height: number; // 0..1 (доля от высоты)
}
```

Это позволяет масштабировать штрихкод до любого размера без потери качества.

## Использование

### Добавление штрихкода

1. Нажмите кнопку "Штрих-код" в левой панели
2. Выберите формат (EAN-13 или ITF-14)
3. Введите код (12-13 цифр для EAN-13, 13-14 для ITF-14)
4. Контрольная цифра добавляется автоматически
5. Нажмите "Добавить"

### Редактирование штрихкода

1. Выберите штрихкод на канвасе
2. В правой панели нажмите "✏️ Изменить код"
3. Внесите изменения в BarcodeModal
4. Нажмите "Обновить"

### Удаление штрихкода

1. Выберите штрихкод на канвасе
2. В правой панели нажмите "🗑️ Удалить штрих-код"

## Подготовка к шагу 6 (PDF экспорт)

Функция `drawBarcodeVectorPDF` готова к использованию:

```typescript
import { drawBarcodeVectorPDF } from './utils/barcodePdfRenderer';

// При экспорте в PDF:
const barcodeData = extractBarcodeData(fabricObject);
if (barcodeData) {
  drawBarcodeVectorPDF(
    doc,
    barcodeData.bars,
    x_mm,      // позиция X на листе
    y_mm,      // позиция Y на листе
    width_mm,  // ширина штрихкода
    height_mm  // высота штрихкода
  );
}
```

Это обеспечит **векторную отрисовку** штрихкодов в PDF — идеально чёткую при любом масштабе.

## Преимущества векторного подхода

### Растровый штрихкод (PNG)
- ❌ Теряет чёткость при масштабировании
- ❌ Мыльные края штрихов
- ❌ Требует высокого DPI для качества
- ❌ Большой размер файла

### Векторный штрихкод (SVG)
- ✅ Идеально чёткие штрихи на ЛЮБОМ DPI
- ✅ Масштабируется без потерь
- ✅ Компактный в PDF
- ✅ Можно редактировать код без пересоздания

## Тестирование

1. Создайте новый проект
2. Нажмите "Штрих-код" в левой панели
3. Выберите EAN-13, введите `460005100005` (12 цифр)
4. Убедитесь, что контрольная цифра добавлена автоматически
5. Нажмите "Добавить"
6. Увеличьте зум канваса — штрихкод остаётся чётким
7. Сохраните проект, загрузите снова — штрихкод восстановлен
8. Выберите штрихкод, нажмите "Изменить код" — можно изменить значение
