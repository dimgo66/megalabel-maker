# Исправления ошибок - PDF дублирование и обрезка изображений

## Проблема 1: Дублирование PDF файлов

### Описание
При загрузке PDF файла создавалось три копии вместо одной.

### Причина
Использование `useState` для флага `isProcessing` приводило к проблемам с замыканием в React. При быстрых повторных вызовах `handleFileSelect` значение `isProcessing` могло не обновляться достаточно быстро, что приводило к множественным вызовам `handleFileUpload`.

### Решение
Заменил `useState` на `useRef` для флага `isProcessing`:

```typescript
// Было:
const [isProcessing, setIsProcessing] = useState(false);

// Стало:
const isProcessingRef = useRef(false);
```

`useRef` обеспечивает мгновенное обновление значения без задержек, связанных с перерисовкой компонента.

### Изменённые файлы
- `src/components/ImagePanel.tsx`:
  - Заменён `useState` на `useRef` для `isProcessing`
  - Добавлены console.log для отладки потока выполнения
  - Улучшена защита от повторных вызовов

- `src/utils/imageLoader.ts`:
  - Добавлены console.log для отслеживания процесса загрузки PDF
  - Подтверждена корректность работы `return` после вызова callback

## Проблема 2: Обрезка изображений не работает

### Описание
При попытке обрезать изображение операция не завершалась корректно.

### Причина
Функция `exitCropMode()` вызывалась сразу после запуска асинхронной операции `fabric.FabricImage.fromURL().then()`, но не ждала её завершения. Это приводило к тому, что `cropRect` удалялся из canvas до того, как использовался для создания нового изображения.

### Решение
Переместил вызов `exitCropMode()` внутрь `.then()`, чтобы он выполнялся только после успешного создания обрезанного изображения:

```typescript
// Было:
fabric.FabricImage.fromURL(croppedDataUrl).then((croppedImg) => {
  // ... операции с изображением
});
exitCropMode(); // Вызывался сразу, не дожидаясь завершения

// Стало:
fabric.FabricImage.fromURL(croppedDataUrl).then((croppedImg) => {
  // ... операции с изображением
  
  // Завершаем режим обрезки ПОСЛЕ создания нового изображения
  setCropRect(null);
  setIsCropping(false);
}).catch((error) => {
  console.error('Ошибка при обрезке изображения:', error);
  alert('Не удалось обрезать изображение');
  exitCropMode();
});
```

Также добавлена обработка ошибок с помощью `.catch()`.

### Изменённые файлы
- `src/components/ImageCropPanel.tsx`:
  - Перемещён вызов завершения режима обрезки внутрь `.then()`
  - Добавлена обработка ошибок
  - Улучшена логика управления состоянием

1. Загрузите PDF файл с несколькими страницами
2. Должен появиться диалог выбора страницы
3. После выбора страницы должна загрузиться только одна копия

7. Режим обрезки должен завершиться автоматически

## Технические детали

### useRef vs useState
- `useState` вызывает перерисовку компонента при изменении значения
- `useRef` обновляет значение мгновенно без перерисовки
- Для флагов, которые используются для синхронизации, `useRef` более подходит

### Асинхронные операции в Fabric.js
- `fabric.FabricImage.fromURL()` возвращает Promise
- Все операции, зависящие от результата, должны выполняться внутри `.then()`
- Важно правильно управлять состоянием компонента при работе с асинхронными операциями
