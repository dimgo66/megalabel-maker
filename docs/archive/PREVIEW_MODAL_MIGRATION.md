# Перенос предпросмотра листа в модальное окно

## Проблема

Предпросмотр листа A4 находился в нижней панели и постоянно перерисовывался при каждом изменении в редакторе. Это вызывало:
- Мелькание и отвлекающий фактор
- Лишнюю нагрузку на производительность
- Невозможность сосредоточиться на редактировании

## Решение

Перенести предпросмотр листа в модальное окно, открываемое по требованию. Рендеринг выполняется только когда окно открыто.

## Созданные файлы

### `src/components/PreviewModal.tsx`

Полноэкранное модальное окно предпросмотра:

**Структура:**
- Размер: 90vw × 90vh
- Закруглённые углы: `rounded-2xl`
- Тень: `shadow-2xl`

**Функциональность:**
- Заголовок с информацией о формате и количестве этикеток
- Панель управления зумом (кнопки [-], [+], слайдер, кнопка "Вписать")
- Чекбокс "Автообновление" (по умолчанию ВКЛ)
- Кнопка "🔄 Обновить" (появляется при выключенном автообновлении)
- Кнопка закрытия ✕
- Закрытие по Esc, по клику на ✕, по клику на фон

**Логика рендеринга:**
- Рендерит лист ТОЛЬКО когда модалка открыта
- При открытии: немедленный рендер
- Пока открыта: автообновление с дебаунсом 500мс при изменениях канваса
- При закрытии: остановка рендеринга, освобождение таймеров

**Оптимизации:**
- Спиннер во время рендеринга для форматов 100+ этикеток
- Cleanup в useEffect return при закрытии
- Кэширование dataURL этикетки

## Преимущества нового подхода

### 1. Производительность
- **До:** Предпросмотр перерисовывался при каждом изменении в редакторе
- **После:** Рендеринг только при открытой модалке
- **Результат:** Нет постоянной нагрузки на CPU/GPU

### 2. UX
- **До:** Мелькание отвлекало от редактирования
- **После:** Предпросмотр по требованию, не мешает работе
- **Результат:** Можно сосредоточиться на редактировании

### 3. Контроль
- **До:** Нет возможности отключить автообновление
- **После:** Чекбокс "Автообновление" + кнопка "Обновить"
- **Результат:** Полный контроль над производительностью

### 4. Пространство
- **До:** Нижняя панель занимала 500px высоты
- **После:** Канвас редактора на всю высоту
- **Результат:** Больше места для работы с этикеткой

## Использование

### Открытие предпросмотра:
1. **Кнопка:** Нажмите "👁 Предпросмотр" в тулбаре
2. **Горячая клавиша:** `Ctrl+Shift+P` (или `Cmd+Shift+P` на Mac)

### Закрытие предпросмотра:
1. **Кнопка ✕:** В правом верхнем углу модалки
2. **Клавиша Esc:** Закрытие по клавише Escape
3. **Клик по фону:** Клик вне модалки закрывает её

### Управление зумом:
- **Кнопки [-] [+]:** Уменьшить/увеличить на 25%
- **Слайдер:** Плавное изменение зума от 25% до 400%
- **Кнопка "Вписать":** Автоматическое масштабирование под размер окна

### Автообновление:
- **Включено (по умолчанию):** Предпросмотр обновляется автоматически с дебаунсом 500мс
- **Выключено:** Обновление только по кнопке "🔄 Обновить"

## Проверка

### В DevTools Performance:
1. Откройте предпросмотр
2. Внесите изменения в редакторе
3. Проверьте, что при закрытой модалке нет активности рендеринга
4. При открытой модалке видны перерисовки с дебаунсом 500мс

## Технические детали

### Дебаунс обновлений:
```typescript
useEffect(() => {
  if (!isOpen || !autoUpdate) return;

  const timeoutId = setTimeout(() => {
    renderSheet();
  }, 500); // Дебаунс 500мс

  return () => clearTimeout(timeoutId);
}, [isOpen, autoUpdate, renderSheet]);
```

### Cleanup при закрытии:
```typescript
useEffect(() => {
  if (!isOpen) return;

  const handleEsc = (e: KeyboardEvent) => {
    if (e.key === 'Escape') {
      onClose();
    }
  };

  window.addEventListener('keydown', handleEsc);
  return () => window.removeEventListener('keydown', handleEsc);
}, [isOpen, onClose]);
```

### Рендеринг только при открытии:
```typescript
useEffect(() => {
  if (!isOpen || !editorCanvas) {
    setCachedDataURL(null);
    return;
  }

  // Генерируем dataURL только когда модалка открыта
  const dataURL = editorCanvas.toDataURL({...});
  setCachedDataURL(dataURL);
}, [isOpen, editorCanvas, labelDesign.canvasJSON, updateCounter]);
```

## Заключение

Перенос предпросмотра в модальное окно решает проблему производительности и UX. Теперь предпросмотр не мешает редактированию, рендерится только по требованию и даёт полный контроль над автообновлением. Центральная область редактора стала больше, что улучшает работу с этикетками.
