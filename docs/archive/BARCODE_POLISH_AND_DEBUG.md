# Полировка раскладки цифр EAN-13 и режим самопроверки

## Обзор

Внесены точечные правки констант для улучшения визуального соответствия штрих-кода EAN-13 эталону и добавлен режим самопроверки "Сетка модулей" для визуальной диагностики раскладки.

## Изменения констант

### buildEan13Norm (src/utils/barcodeGenerator.ts)

**Было → Стало:**

| Параметр | Было | Стало | Назначение |
|----------|------|-------|------------|
| `leftPadMod` | 7 | **8** | Увеличен запас слева под первую цифру |
| `firstDigitX` | -3.5 | **-4.2** | Первая цифра чуть левее, зазор как в эталоне |
| `fontMod` | 9 | **8.5** | Ряд цифр чуть мельче, аккуратнее |
| `digitYMod` | 56 | **55** | Ряд чуть выше, не касается безопасного поля |
| `DATA_BAR_H_MOD` | 44 | 44 | Без изменений |
| `GUARD_BAR_H_MOD` | 53 | 53 | Убедиться что применяется |

**Позиции групп НЕ изменены** (они стандартные):
- Левые цифры: `6.5 + 7*i` (i = 0..5)
- Правые цифры: `53.5 + 7*j` (j = 0..5)

### Результат полировки

✅ Зазор между первой цифрой и левой группой увеличен  
✅ Ряд цифр компактный, не касается безопасного поля  
✅ Удлинённые защитные штрихи (2/2/2) опускаются между цифрами  
✅ Визуальное соответствие эталону EAN-13  

## Режим самопроверки "Сетка модулей"

### Описание

Одноразовый режим визуальной диагностики раскладки штрих-кода. При включении поверх канваса отображается оверлей с линиями:

- **Серые вертикальные линии** - центры всех 13 цифр
- **Зелёные вертикальные линии** - границы зон защитных штрихов (0, 3, 45, 50, 92, 95 модулей)
- **Розовая горизонтальная линия** - базовая линия цифр (digitYMod)

### Реализация

### Использование

1. Создайте штрих-код EAN-13
2. Выберите его на канвасе
3. Включите чекбокс "🔍 Сетка модулей" в заголовке канваса
4. Проверьте:
   - ✅ Каждая цифра отцентрована по своей серой линии
   - ✅ Левая группа строго между зелёными 3 и 45
   - ✅ Правая группа между 50 и 92
   - ✅ Первая цифра левее зелёной 0
   - ✅ Розовая линия проходит через базовую линию цифр
5. Выключите сетку для финального вида

### Легенда оверлея

При включённом режиме в правом верхнем углу отображается легенда:
- Серая линия - Центры цифр
- Зелёная линия - Границы зон
- Розовая линия - Базовая линия

## Численная самопроверка

### console.table в buildBarcodeGroup

При создании штрих-кода EAN-13 в консоль выводится таблица с позициями цифр:

```typescript
if (norm.format === 'ean13') {
  console.table(
    norm.digits.map(d => ({
      char: d.char,
      xMod: d.xMod,
      px: (norm.leftPadMod + d.xMod) * norm.pxPerModule

  );
}
```

```typescript
const expectedWidth = (norm.leftPadMod + norm.modulesTotal + 1) * px; // +1 модуль правый запас
```

## Миграция старых проектов

При загрузке проекта со старой структурой `barcodeNorm`:
- Автоматически определяется отсутствие новых констант
- Штрих-код пересоздаётся через `buildBarcodeGroup` с новыми константами
- Сохраняются позиция, масштаб и поворот

Кнопка "🔄 Пересоздать штрих-код" в панели свойств также использует новые константы.

## Технические детали

### Формулы расчёта позиций

**Для точек внутри группы:**
```typescript
px = (leftPadMod + xMod) * pxPerModule
```

**Для ширин (БЕЗ leftPad!):**
```typescript
widthPx = wMod * pxPerModule
```

### Пример расчёта для кода 4604335164275

**Группа:**
- Ширина: (8 + 95 + 1) * 4 = **416 px**
- Высота: (55 + 8.5) * 4 = **254 px**

**Штрихи:**
- 1 модуль: 1 * 4 = **4 px**
- 4 модуля: 4 * 4 = **16 px**

**Цифры:**
- Первая (4): (8 + (-4.2)) * 4 = **15.2 px**
- Вторая (6): (8 + 6.5) * 4 = **58 px**
- Седьмая (5): (8 + 41.5) * 4 = **198 px**
- Восьмая (1): (8 + 53.5) * 4 = **246 px**
- Тринадцатая (5): (8 + 88.5) * 4 = **386 px**

**Защитные штрихи:**
- Start guard (модули 0-2): высота 53 * 4 = **212 px**
- Center guard (модули 45-49): высота **212 px**
- End guard (модули 92-94): высота **212 px**

**Штрихи данных:**
- Высота: 44 * 4 = **176 px**

## Преимущества

1. **Точная полировка** - константы подобраны для визуального соответствия эталону
2. **Визуальная диагностика** - режим сетки модулей позволяет быстро проверить раскладку
