# Активные шаблоны — точная геометрия из .doc (docs/шаблоны)

Источник данных: `_tools/doc_geometry_report.txt` — прямой парсинг Word 97-2003
(FIB → PlcfSed/SEPX → поля страницы; PAPX → sprmTDefTable → сетка таблицы,
sprmTDyaRowHeight → высота ряда). Все размеры в twips переведены в мм (1 мм = 56.6929 tw).

## Как читать раскладку

Каждый шаблон задаётся в `src/config/labelFormats.ts` через
`geometryFromMargins(left, top, cellW, cellH, cols, rows, pitchX, pitchY)`:

- `left/top` — позиция первой ячейки от левого верхнего угла A4 (поле страницы);
- `pitchX/pitchY` — шаг сетки (лево ячейки → лево следующей);
- `cellW/cellH` — размер самой этикетки;
- `cols/rows` — сетка; `count = cols × rows`.

Проверка: `left + pitchX·(cols−1) + cellW + restRight = 210`,
`top + pitchY·(rows−1) + cellH + restBottom = 297`.

### Примечания по шаблонам

- **99×34, 66.7×46** — клетка таблицы Word (шаг) шире этикетки: 101.51 против 99.00
  и 68.70 против 66.70. Этикетка вставлена в клетку; поле клетки = поле страницы
  (в .doc поля страницы 4.74/2.95 мм совпадают с этим расчётом). Шаг сохранён точно.
- **⌀60 круг** — в .doc нет фигур-кругов: это «шахматная» таблица из широких ячеек
  2410 tw (42.51 мм) и разделителей 1361 tw (24.01 мм). Центры широких ячеек:
  X = 2137 tw = 37.70 мм, Y = 2719 tw = 47.96 мм от края листа →
  левый верх круга ⌀60: 7.70 / 17.96 мм. Шаг центров 3771 tw = 66.52 мм.
- **105×57, 52.5×35, 38×16.9** — этикетка равна клетке (шаг = ширине), вплотную.

## Деактивированные форматы

Прежние 40 форматов (`210x297_1` … `18x12_230`) перенесены в
`INACTIVE_LABEL_FORMATS` в `src/config/labelFormats.ts` — их нет в селекторе,
но они доступны для восстановления (раскладка у них считается автоматически
по центру листа, геометрия .doc не задана).

## Куда подставлена геометрия

- `src/utils/layoutCalculator.ts` — `calculateLayout()` отдаёт поля/шаг/размер
  ячейки из `format.layout` (приоритет) либо авто-раскладку;
  `gridPitch()` — единая точка получения шага сетки.
- `src/components/PreviewModal.tsx` — предпросмотр листа (позиция = поле + шаг×индекс).
- `src/components/FormatSelector.tsx` — миниатюры в масштабе листа A4.
- `src/utils/pdfExporter.ts` — растровый лист (`composeSheetCanvas`, fallback).
- `src/utils/vectorExporter.ts` — векторный PDF (`exportToVectorPDF`).
- Печать (`printManager.ts`) идёт через те же экспортёры — правки не требовались.
