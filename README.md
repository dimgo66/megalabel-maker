# 🏷️ Megalabel Pro - Label Maker

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/dimgo66/megalabel-maker)

Профессиональное веб-приложение для создания и печати этикеток на листах A4 с поддержкой векторных штрих-кодов и PDF экспорта.

## ✨ Возможности

### Основные функции
- 📐 **50+ форматов этикеток** - от 18×12 мм до 210×297 мм
- ✏️ **Визуальный редактор** - добавление текста, изображений, штрих-кодов
- 🔤 **Поддержка шрифтов** - системные, Google Fonts с кириллицей, пользовательские (.ttf, .otf)
- 📊 **Векторные штрих-коды** - EAN-13, ITF-14 с идеальной чёткостью при любом масштабе
- 🖼️ **Загрузка изображений** - PNG, JPG, SVG, PDF с автоматическим масштабированием
- ✂️ **Обрезка изображений** - интерактивный редактор с визуальной рамкой
- 👁️ **Предпросмотр листа A4** - тиражирование этикетки на все позиции сетки
- 💾 **Автосохранение** - восстановление проекта при перезагрузке страницы
- ↩️ **Undo/Redo** - полная история изменений

### Экспорт и печать
- 📄 **Векторный PDF экспорт** - штрих-коды и текст остаются векторными
- 🖨️ **Прямая печать** - через PDF-окно или браузер
- 🎯 **Точные размеры** - соответствие мм формата
- 🔄 **Fallback на растр** - автоматический переход на растровый экспорт при ошибке векторного

### Ассеты PDF

Wasm-декодеры pdf.js (JPEG2000, JBIG2, ICC-профили), таблицы CMap и стандартные
шрифты копируются из `node_modules/pdfjs-dist` в `public/pdfjs` автоматически
перед `dev` и `build` скриптом `scripts/sync-pdfjs-assets.mjs`. Без них PDF с
JPEG2000/JBIG2 вставляются с потерянными изображениями. Отдельный запуск —
`npm run pdfjs:sync`.

### Сборка pdf.js

Приложение использует **legacy**-сборку pdf.js (`pdfjs-dist/legacy/build/*`):
она транспилирована и несёт core-js-полифилы, поэтому PDF вставляется и в
браузерах без новых методов `Uint8Array` (`toHex`, `toBase64`). Современная
сборка в них падает при открытии файла с «n.toHex is not a function» —
типично для устаревших корпоративных браузеров (Яндекс Браузер на старом
Chromium, Firefox ESR). Минимальный уровень: Chromium 119+, Firefox ESR.
Импорт и воркер обязаны быть из одной сборки — иначе pdf.js ругается на
несовпадение версий.

### Шрифты и векторная печать

Векторный экспорт/печать регистрирует в jsPDF **только** семейства, реально
используемые на этикетке, а fallback-шрифт (Roboto Condensed regular/bold)
вшит в бандл base64 (`src/config/fallbackFontData.ts`) и грузится ленивым
импортом только при печати. Поэтому векторная печать не падает, когда
офисная сеть блокирует или обрывает запросы к `/fonts/*.ttf` — раньше это
давало «Failed to fetch» и переход на растр. Если файл fallback-шрифта в
`public/fonts` меняется, перегенерируйте base64:
`node scripts/embed-fallback-font.mjs`.

### Превью вставленного PDF

Страница вставленного PDF на холсте редактора всегда растровая — fabric не
умеет рисовать страницу PDF векторно. Плотность превью считается от экрана и
зума (`src/utils/previewDensity.ts`: 96 dpi × зум × devicePixelRatio, но не
ниже 288 dpi), а когда зум её перерастает, страница дорисовывается заново из
байтов в `pdfSources` (`src/utils/pdfPreview.ts`, дебаунс 300 мс, шаг зума до
500%). Потолок — 1200 dpi и 24 Мпикс на страницу: A4 при 900 dpi это 78 Мпикс
и подвис браузера, поэтому для крупных страниц плотность подрезается.

В файл проекта и в автосохранение уходит копия плотности вставки
(`srcPdfLowSrc`), иначе резкое превью на 500% раздувало бы JSON в разы. В
векторный экспорт и печать превью не попадает: там исходная страница PDF
(`embedPdf`).

## 🔧 Особенности реализации

### Векторные штрих-коды
- Единая структура `BarcodeNorm` для всех операций
- Хранение в модулях (не в долях)
- Детерминированная генерация EAN-13
- Индивидуальная высота для защитных штрихов
- Режим самопроверки "Сетка модулей"

### Векторный PDF экспорт
- Трёхслойная архитектура:
  1. Сцена этикетки (fabric → SVG → jsPDF)
  2. Вставки PDF (pdf-lib embedPdf)
  3. Сборка листа A4 (pdf-lib)
- Fallback на растровый экспорт при ошибке
- Preflight-проверки перед экспортом

### Безопасные поля
- Настраиваемый отступ (0-10 мм), по умолчанию 1 мм
- Визуализация в редакторе (красные зоны)
- Не отображаются на предпросмотре листа

### Обрезка изображений
- Интерактивная рамка обрезки
- Полупрозрачный оверлей
- Блокировка других объектов
- Сохранение в проект
