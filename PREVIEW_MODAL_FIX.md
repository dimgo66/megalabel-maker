# ✅ Исправлена проблема с превью в PreviewModal

## Проблема

Превью листа в модальном окне не отображалось - пустой canvas без содержимого.

## Причина

В `PreviewModal.tsx` изображение загружалось асинхронно через `new Image()`, но код не ждал его загрузки перед отрисовкой. Это та же ошибка, что была ранее в `composeSheetCanvas`.

**Было (неправильно):**
```typescript
const labelImg = new Image();
labelImg.onload = () => {
  // Пытаемся рисовать, но изображение ещё не готово!
  ctx.drawImage(labelImg, x_px, y_px, cellW_px, cellH_px);
};
labelImg.src = cachedDataURL;
```

## Решение

Добавлено ожидание загрузки изображения через `await labelImg.decode()`:

**Стало (правильно):**
```typescript
const labelImg = new Image();
labelImg.src = cachedDataURL;

labelImg.onload = async () => {
  // Ждём полной загрузки и декодирования изображения
  await labelImg.decode();
  
  // Теперь можно безопасно рисовать
  ctx.drawImage(labelImg, x_px, y_px, cellW_px, cellH_px);
};

labelImg.onerror = () => {
  console.error('Ошибка загрузки изображения для превью');
  setIsRendering(false);
};
```

## Изменения в коде

### src/components/PreviewModal.tsx

**1. Добавлен `await labelImg.decode()`**
```typescript
labelImg.onload = async () => {
  // Ждём полной загрузки изображения
  await labelImg.decode();
  
  // Рендерим каждую ячейку

};
```

**2. Убрано дублирование `labelImg.src`**
```typescript
// Было:

// ... код ...
labelImg.src = cachedDataURL;  // строка 138 (дублирование)

// Стало:
labelImg.src = cachedDataURL;  // только один раз
```

**3. Добавлена обработка ошибок**
```typescript
labelImg.onerror = () => {
  console.error('Ошибка загрузки изображения для превью');
  setIsRendering(false);
};
```

## Почему img.decode()?

Метод `img.decode()` возвращает Promise, который разрешается, когда изображение:
- ✅ Полностью загружено
- ✅ Декодировано браузером
- ✅ Готово к отрисовке на canvas

Без этого `ctx.drawImage()` может рисовать пустое или частично загруженное изображение.

### Поток выполнения:

1. Пользователь открывает PreviewModal
2. `useEffect` генерирует `cachedDataURL` из `editorCanvas`
