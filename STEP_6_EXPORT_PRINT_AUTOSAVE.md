# Шаг 6: Экспорт в PDF, печать и автосохранение

## Обзор

Реализован полный функционал экспорта и печати этикеток с векторными штрихкодами, а также система автосохранения проектов.

## Архитектура экспорта

### Слои в PDF:
1. **РАСТР высокого DPI**: текст, изображения, фон (всё КРОМЕ штрихкодов)
2. **ВЕКТОР**: штрихи штрихкодов через `drawBarcodeVectorPDF`
3. **ВЕКТОРНЫЙ ТЕКСТ**: цифры штрихкода поцифрово через `computeDigitPositions`

## Созданные файлы

### 1. `src/utils/pdfExporter.ts`

Основные функции экспорта:

#### `renderLabelRaster(canvas, format, dpi): string`
- Рендерит растр этикетки без штрихкодов
- Временно скрывает объекты с `barcodeValue`
- Для круглых этикеток убирает фон
- Возвращает dataURL PNG

#### `collectBarcodes(canvas, format): BarcodePlacement[]`
- Собирает данные о всех штрихкодах на канвасе
- Конвертирует координаты из пикселей в мм
- Возвращает массив с позициями и данными штрихкодов

#### `exportToPDF(cfg): Promise<jsPDF>`
- Создаёт PDF документ формата A4
- Для каждой ячейки:
  - Для круглых: рисует белый круг
  - Добавляет растр этикетки
  - Рендерит штрихи векторно через `drawBarcodeVectorPDF`
  - Рисует цифры поцифрово через `computeDigitPositions`
- Возвращает готовый jsPDF документ

#### `composeSheetCanvas(cfg, dpi): HTMLCanvasElement`
- Создаёт offscreen canvas листа A4
- Рендерит все ячейки с растрами и штрихкодами
- Используется для превью экспорта и браузерной печати

### 2. `src/utils/printManager.ts`

Функции печати:

#### `printViaPdfWindow(cfg): Promise<void>`
- **Рекомендуемый способ**
- Создаёт PDF через `exportToPDF`
- Открывает в новом окне для печати
- Векторные штрихкоды, точные размеры

#### `printViaBrowser(cfg, dpi): void`
- Альтернативный способ
- Создаёт растровое изображение через `composeSheetCanvas`
- Вставляет в `div#direct-print-area`
- Вызывает `window.print()`
- Работает, если PDF не открывается

## Использование

### Экспорт в PDF

1. **Кнопка:** Нажмите "📄 PDF" в тулбаре
2. **Горячая клавиша:** `Ctrl+Shift+E`
3. Выберите качество (DPI)
4. Нажмите "Скачать PDF"

### Печать

1. **Кнопка:** Нажмите "🖨️ Печать" в тулбаре
2. **Горячая клавиша:** `Ctrl+P`
3. Выберите способ печати:
   - **Открыть PDF** (рекомендуется) - векторные штрихкоды
   - **Печать через браузер** - растровая печать
4. Нажмите "Печать"
5. В диалоге печати настройте:
   - Поля: НЕТ
   - Масштаб: 100%
   - Ориентация: из настроек
   - Цвет: Чёрно-белый

### Автосохранение

- Автоматически каждые 30 секунд при наличии изменений
- При перезагрузке страницы: баннер восстановления
- Кнопка "Восстановить" - загрузить автосохранение
- Кнопка "Удалить" - удалить автосохранение

## Технические детали

### Векторные штрихкоды в PDF

Штрихи рисуются через `doc.rect()` - это векторные прямоугольники, которые:
- Масштабируются без потери качества
- Имеют чёткие края при любом зуме
- Занимают мало места в PDF

### Поцифровая отрисовка цифр

Для EAN-13:
```typescript
const positions = computeDigitPositions(bc.bars, 'ean13', bc.value);
// Первая цифра слева вне штрихов
// 6 цифр под левой половиной
// 6 цифр под правой половиной

for (const p of positions) {
  doc.text(p.char, x + p.xFrac * w, y + textY * h, {
    align: 'center',
    baseline: 'middle'
  });
}
```

### Автосохранение

```typescript
// Каждые 30 секунд
setInterval(() => {
  if (isDirty) {
    const json = serializeProject(labelDesign, sheetSettings);
    localStorage.setItem('label-maker-autosave', json);
  }
}, 30000);
```

### Рендеринг растра без штрихкодов

```typescript
// Временно скрываем штрихкоды
canvas.getObjects().forEach(obj => {
  if (obj.barcodeValue) {
    obj.set('visible', false);
  }
});

// Рендерим растр
const dataURL = canvas.toDataURL({ format: 'png', multiplier });

// Восстанавливаем видимость
canvas.getObjects().forEach(obj => {
  if (obj.barcodeValue) {
    obj.set('visible', true);
  }
});
```
