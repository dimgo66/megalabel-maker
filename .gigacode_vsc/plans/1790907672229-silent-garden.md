# План: Объединение предпросмотра, PDF и печати

## Проблема
1. Старый PreviewModal отображается неправильно (растр с canvas, а не через composeSheetCanvas)
2. ExportModal и PrintModal — отдельные окна, неудобно
3. В ExportModal показывается лишний текст "1200 DPI"
4. PrintModal открывается пустым (iframe блокируется браузером)

## Решение
Объединить всё в одно окно "Предварительный просмотр" с:
- Предпросмотром листа A4 с зумом (как в старом PreviewModal, но на основе composeSheetCanvas)
- Кнопкой "Скачать PDF"
- Кнопкой "Печать" с выбором способа (PDF / Браузер)
- Масштабированием просмотра (zoom slider)

**Компоненты:**

**Использовать:**
- `composeSheetCanvas()` для генерации превью (как в старом ExportModal)
- `exportWithFallback()` для PDF
- `printViaPdfWindow()` / `printViaBrowser()` для печати
- `previewZoom` из store для зума

## Шаг 3: Обновить App.tsx

**Изменения:**
1. Удалить импорты `ExportModal`, `PrintModal`
2. Заменить на импорт нового `PreviewModal`
3. Удалить state `isExportOpen`, `isPrintOpen`
4. Оставить только `isPreviewOpen`
5. Заменить `<ExportModal>` и `<PrintModal>` на один `<PreviewModal>`
6. Обновить хоткеи: `onPreview` открывает PreviewModal, `onExport` тоже открывает PreviewModal (или удаляем onExport)

**Было:**
```tsx
const [isPreviewOpen, setIsPreviewOpen] = useState(false);
const [isExportOpen, setIsExportOpen] = useState(false);
const [isPrintOpen, setIsPrintOpen] = useState(false);

<PreviewModal isOpen={isPreviewOpen} onClose={() => setIsPreviewOpen(false)} />
<ExportModal isOpen={isExportOpen} onClose={() => setIsExportOpen(false)} />
<PrintModal isOpen={isPrintOpen} onClose={() => setIsPrintOpen(false)} />
```

**Стало:**
```tsx
const [isPreviewOpen, setIsPreviewOpen] = useState(false);

<PreviewModal isOpen={isPreviewOpen} onClose={() => setIsPreviewOpen(false)} />
```
