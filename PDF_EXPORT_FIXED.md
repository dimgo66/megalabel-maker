# 🎉 Проблема с пустым PDF решена!

## Что было исправлено

### Основная проблема
При экспорте в PDF получался пустой файл без содержимого.

### Причина
Функция `composeSheetCanvas` загружала изображение асинхронно, но не ждала его загрузки перед отрисовкой на canvas. В результате на canvas рисовалось пустое изображение.

### Решение
1. ✅ Функция `composeSheetCanvas` теперь **асинхронная** и использует `await img.decode()` для ожидания загрузки изображения
2. ✅ Все вызовы функции обновлены с `await`
3. ✅ Функция `printViaBrowser` стала асинхронной
4. ✅ Все вызовы `printViaBrowser` обновлены с `await`

## Изменённые файлы

src/components/ExportModal.tsx    - await composeSheetCanvas()

## Технические детали

### Было (неправильно):
```typescript
export function composeSheetCanvas(...): HTMLCanvasElement {
  const img = new Image();
  img.src = raster;
  // ❌ Сразу рисуем - изображение ещё не загружено!
  ctx.drawImage(img, x_px, y_px, cellW_px, cellH_px);
  return canvas;
}
```

### Стало (правильно):
```typescript
export async function composeSheetCanvas(...): Promise<HTMLCanvasElement> {
  const img = new Image();
  img.src = raster;
  await img.decode(); // ✅ Ждём загрузки изображения!
  ctx.drawImage(img, x_px, y_px, cellW_px, cellH_px);
  return canvas;
}
```

### Почему img.decode()?

Метод `img.decode()` возвращает Promise, который разрешается, когда изображение:
- ✅ Полностью загружено
- ✅ Декодировано браузером
- ✅ Готово к отрисовке

Это самый чистый и современный способ ожидания загрузки изображения.
